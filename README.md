# lisansustu-app

Yüksek lisans ve doktora başvurularını tek yerde toplayan, kabul ihtimalini tahmin eden ve ALES/YDS hazırlık içerikleri sunan platform.

## Yapı

- `apps/web`: Next.js web sitesi
- `packages/core`: Web ve ileride mobil uygulamanın paylaşacağı iş mantığı (veri tipleri, eşleştirme motoru)

## Çalıştırma

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build
```
